= Manage policies
:icons: font
:imagesdir: ../media/

[.lead]
Use the Policies page to stay on top of your data governance criteria. For example, a storage administrator who created several cold-data policies can check the impacted file count for each one to prioritize which data populations need attention first.

== Navigate to Policies

From the AI Data Engine left navigation, click *Policies*.

.About this task
The Policies page lists all policies you have created. Each entry shows:

[cols="1,2",options="header"]
|===
|Column |Description

|Name
|The name assigned when the policy was created.

|Created
|Whether the policy is *Custom* (user-created) or *Predefined*.

|Actions
|The action configured for the policy (for example, Email update).

|Description
|The filter criteria expression for the policy.

|Impacted files and objects
|The count of files and objects currently matching the policy criteria (for example, 654k).

|===

== View a policy

.Steps
. From the AI Data Engine left navigation, click *Policies*.
. Click *View* next to the policy to see the full policy details and impacted items.

== Delete a policy

WARNING: Deletion is permanent and cannot be undone.

.Steps
. From the AI Data Engine left navigation, click *Policies*.
. Open the action menu for the policy you want to delete and select *Delete policy*.
. Confirm the deletion in the preview dialog.
