= Manage policies in AI Data Engine
:icons: font
:imagesdir: ../media/

[.lead]
When you want to review which of your saved policies are matching data, compare impacted file counts to prioritize, or remove policies you no longer need, use the Policies page to manage them. For example, a storage administrator with several cold-data policies can compare the impacted file count across policies to decide which data groupings need attention first.

Each policy listing shows the count of files and objects currently matching its criteria. Use this count to identify which policies are actively capturing data worth reviewing.

== Check which files match a policy

Before committing to edit or delete a policy, review the files it currently matches to confirm the criteria are still capturing the right data.

.Steps
. From the AI Data Engine UI, select *Policies*.
. Open the action menu next to the policy and select *Investigate results*.

== Edit a policy

.Before you begin
* You must have the _AI Data Engine administrator_ role.

.Steps
. From the AI Data Engine UI, select *Policies*.
. Open the action menu for the policy you want to edit and select *Edit policy*.
. Update the policy name, description, or action as needed.
. Select *Save*.

== Delete a policy

.Before you begin
* You must have the _AI Data Engine administrator_ role.

CAUTION: Deletion is permanent and cannot be undone.

.Steps
. From the AI Data Engine UI, select *Policies*.
. Open the action menu for the policy you want to delete and select *Delete policy*.
. Confirm the deletion in the preview dialog.
