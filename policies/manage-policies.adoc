= Manage policies in AI Data Engine
:icons: font
:imagesdir: ../media/

[.lead]
Use the Policies page to review your saved policies, check the current file count for each criteria set, and remove policies you no longer need. For example, a storage administrator with several cold-data policies can compare the impacted file count across policies to decide which data groupings need attention first.

== Navigate to Policies

From the AI Data Engine UI, select *Policies*.

.About this task
The Policies page lists all policies you have created. Each entry shows:

[cols="1,2",options="header"]
|===
|Column |Description

|Name
|The name assigned when the policy was created.

|Created by
|The name of the user who created the policy.

|Actions
|The action configured for the policy (for example, *Send email notification*).

|Description
|The filter criteria expression for the policy.

|Impacted files and objects
|The count of files and objects currently matching the policy criteria (for example, 654k).

|===

== View a policy

.Steps
. From the AI Data Engine UI, select *Policies*.
. Open the action menu next to the policy and select *Investigate results* to see the full policy details and impacted items.

== Edit a policy

.Before you begin
* You must have the _AI Data Engine administrator_ role.

.Steps
. From the AI Data Engine UI, select *Policies*.
. Open the action menu for the policy you want to edit and select *Edit policy*.
. Update the policy name, description, or action as needed.
. Select *Save*.

== Delete a policy

.Before you begin
* You must have the _AI Data Engine administrator_ role.

CAUTION: Deletion is permanent and cannot be undone.

.Steps
. From the AI Data Engine UI, select *Policies*.
. Open the action menu for the policy you want to delete and select *Delete policy*.
. Confirm the deletion in the preview dialog.
