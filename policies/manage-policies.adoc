= Manage policies
:icons: font
:imagesdir: ../media/

[.lead]
View and manage policies from the Policies page. You can enable or disable policies, edit policy criteria, and delete policies you no longer need.

.About this task
The Policies page lists all policies you have created. Each entry shows:

[cols="1,2",options="header"]
|===
|Column |Description

|Policy name
|The name assigned when the policy was created.

|Query / criteria
|A summary of the filter criteria the policy evaluates.

|Action
|The action configured to run when files match the policy.

|Status
|Whether the policy is enabled or disabled.

|===
