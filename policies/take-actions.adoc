= Take action on your data in AI Data Engine
:icons: font
:imagesdir: ../media/

[.lead]
After identifying files that are consuming unnecessary storage, take direct action to reclaim capacity or enforce your organization's data lifecycle policies. For example, a storage administrator who filters to find terabytes of VM snapshots not accessed in over a year can archive them in bulk to a cold storage share, freeing that space for active workloads.

.About this task
To take action, select one or more items in the Investigation results table using the checkboxes. The action toolbar activates with four options: *Delete*, *Archive*, *Copy*, and *Tag*.

The actions available to you depend on your assigned role:

== Decide what to do

Choose an action based on how certain you are about the data:

[cols="1,2",options="header"]
|===
|Action |When to use it

|Tag
|You need more time, or need to coordinate with another team, before committing to archive or delete. Tagging tracks the files without changing where they live.

|Archive
|The data may still have value, but it doesn't belong in primary storage. Archiving moves it to a lower-cost destination while keeping it recoverable.

|Copy
|The data should exist in a second location, for example for backup or migration purposes. Copying preserves the original in place.

|Delete
|The data is confirmed worthless and safe from a retention standpoint. Deletion is permanent, so use it only when you are sure.

|===

When data may still have value or requires further review, prefer tagging, archiving, or copying over deleting. Only delete when you are certain the data is safe to remove permanently.

== Archive

Archiving moves files to a cold storage destination over NFS or CIFS. You can optionally leave a breadcrumb file at the original location.

.Before you begin
* You must have the _AI Data Engine administrator_ role.

.Steps
. In the Investigation view, select the files you want to archive.
. Click *Archive*.
. In the Archive dialog, select the destination volume protocol:
+
* *NFS*: enter the NFS destination folder path.
* *CIFS*: enter the CIFS destination folder path in the format `\\Hostname\share_name`. Provide Active Directory credentials: enter the username in `domain\user` or `user@domain` format, and enter the password.
. To create a breadcrumb file at the original location, enable *Leave breadcrumb*.
+
A breadcrumb file helps users understand why a file was moved.
. Click *Archive*.

== Copy

Copying duplicates files to a destination volume without removing them from the original location.

.Before you begin
* You must have the _AI Data Engine administrator_ role.

.Steps
. In the Investigation view, select the files you want to copy.
. Click *Copy*.
. In the Copy dialog, select the destination volume protocol:
+
* *NFS*: enter the NFS destination folder path.
* *CIFS*: enter the CIFS destination folder path in the format `\\Hostname\share_name`. Provide Active Directory credentials: enter the username in `domain\user` or `user@domain` format, and enter the password.
. Click *Copy*.

== Delete

Deleting permanently removes files from storage and cannot be undone.

CAUTION: Deletion is permanent and cannot be undone. This action deletes source files even if they contain active data.

.Before you begin
* You must have the _AI Data Engine administrator_ role.

.Steps
. In the Investigation view, select the files you want to delete.
. Click *Delete*.
. In the Delete dialog, type *permanently delete* in the confirmation field.
. Click *Delete*.

.Result
The selected files are permanently deleted from storage.

== Tag

Tagging applies a business tag to files for classification and tracking.

.Steps
. In the Investigation view, select the files you want to tag.
. Click *Tag*.
. Enter or select the tags to apply (for example, "Archive candidate").
. Confirm to apply the tags.
