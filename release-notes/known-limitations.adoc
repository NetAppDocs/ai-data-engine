= Known limitations in AI Data Engine
:icons: font
:imagesdir: ../media/

[.lead]
Known limitations identify functionality that isn't supported in this release of AI Data Engine, or functionality that doesn't interoperate correctly. Review these limitations before deploying or using the product.

== Deployment

Single-node and multi-node deployments are independent::
An AIDE single-node deployment and an AIDE multi-node deployment are separate deployment types. There is no supported migration path to move an existing deployment from one type to the other.

== Policies and actions

Policy-triggered actions are limited::
When you create a policy, the available automated actions are limited to permanent deletion and email notification. Automated archive and tag actions from policies are not available in this release. You can create a policy with no action to monitor a data condition over time.

== Tags

Tags can't be deleted or renamed::
Tag management isn't available in this release. After you create a tag, it remains available in the system. You can apply a tag to items and remove it from items, but you can't delete the tag definition itself or correct a tag name that contains a typo. 

== Governed AI Access (MCP)

MCP supports only collection-scoped metadata search and tag management::
AI clients that connect through MCP can search the metadata in collections that you enable for AI access, and they can manage tags. No other operations are available.

MCP search filters are limited::
AI clients can search files by name prefix, file type, and owner only. If you ask for files by size, date, or folder, the AI client must page through results, and the answer might be incomplete.

MCP tag operations are limited::
AI clients can list tags and how many files have each tag, and they can add or remove a tag on one file at a time. Tags apply across AI Data Engine, not only to one collection. AI clients can't list the files that have a tag, or delete or rename a tag.

MCP doesn't retrieve file contents::
AI clients can't retrieve the contents of files through MCP in this release.

MCP doesn't support file changes or data source changes::
AI clients can't add, delete, or modify files, and they can't change data sources.

Access is granted at the collection level only::
You grant Microsoft Entra ID scopes access to entire collections. You can't grant access to individual files or directories.

Microsoft Entra ID is the only supported identity provider::
Governed AI Access supports Microsoft Entra ID for authentication. Other identity providers aren't supported.

Only three AI clients are supported::
Claude Desktop, Cursor, and Visual Studio Code with GitHub Copilot are the supported AI clients. Other MCP clients aren't supported.
