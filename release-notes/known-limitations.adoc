= Known limitations in AI Data Engine
:icons: font
:imagesdir: ../media/

[.lead]
Known limitations identify functionality that is not supported in this release of AI Data Engine, or functionality that does not interoperate correctly. Review these limitations before deploying or using the product.

== Deployment

Lite to Enterprise migration is not available in this release::
You cannot migrate an existing AIDE Lite deployment to AIDE Enterprise in this release.

== Policies and actions

Policy-triggered actions are limited::
When you create a policy, the available automated actions are limited to permanent deletion and email notification. Automated archive and tag actions from policies are not available in this release. You can create a policy with no action to monitor a data condition over time.
