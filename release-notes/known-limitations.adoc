= Known limitations in AI Data Engine
:icons: font
:imagesdir: ../media/

[.lead]
Known limitations identify functionality that is not supported in this release of AI Data Engine, or functionality that does not interoperate correctly. Review these limitations before deploying or using the product.

== Deployment

Lite to Enterprise migration is not available in this release::
You cannot migrate an existing AIDE Lite deployment to AIDE Enterprise in this release. A supported migration path is planned for a future release.

== Scanning and data sources

No content classification or inspection::
AI Data Engine catalogs link:../get-started/architecture.html[file and directory metadata] only. It does not inspect file contents, perform data classification, detect personally identifiable information (PII), or apply content-based labels. Filtering and policy conditions are based on metadata attributes such as file size, access time, modification date, creation date, file type, and tags.

== Policies and actions

Available actions are Tag, Archive, and Delete::
When you take action on files from Investigation results, the available actions are Tag, Archive, and Delete. The Copy action is not available in this release. Archive moves files to a user-specified NFS or CIFS destination.

Policy-triggered actions are limited::
When you create a policy, the available automated actions are limited to permanent deletion and email notification. Automated archive and tag actions from policies are not available in this release. You can create a policy with no action to monitor a data condition over time.
