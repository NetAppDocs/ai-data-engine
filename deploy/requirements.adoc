= Requirements
:icons: font
:imagesdir: ../media/

[.lead]
Review these requirements before deploying AI Data Engine.

== ONTAP requirements

// RESEARCH NEEDED: Confirm the minimum ONTAP version required. Not confirmed in available source material — check with engineering or the MIS PRD.

* NetApp ONTAP [version TBD] or later
* NFS or CIFS/SMB protocols enabled on volumes you want to scan

== Networking requirements

The following network connections must be open:

[cols="2,1,1,1,2",options="header"]
|===
|Connection |Port |Protocol |Direction |Purpose

|Console Agent ↔ NetApp Console
|443
|TCP
|Outbound
|HTTPS: connectivity to NetApp Console

|Console Agent ↔ ONTAP
|443
|TCP
|Outbound
|HTTPS: ONTAP cluster discovery

|AI Data Engine ↔ ONTAP (NFS)
|111, 2049
|TCP/UDP
|To storage
|NFS data source access

|AI Data Engine ↔ ONTAP (CIFS/SMB)
|139, 445
|TCP/UDP
|To storage
|CIFS/SMB data source access

|AI Data Engine ↔ Active Directory
|389, 636, 3268, 3269
|TCP/UDP (389)
|Outbound
|LDAP/LDAPS: user authentication and CIFS scanning

|===
