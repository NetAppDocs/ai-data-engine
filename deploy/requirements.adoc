= AI Data Engine requirements
:icons: font
:imagesdir: ../media/

[.lead]
Review these requirements before deploying AI Data Engine.

== Networking requirements

The following network connections must be open:

[cols="2,1,1,1,2",options="header"]
|===
|Connection |Port |Protocol |Direction |Purpose

|Console Agent to NetApp Console
|443
|TCP
|Outbound
|HTTPS: connectivity to NetApp Console

|Console Agent to ONTAP
|443
|TCP
|Outbound
|HTTPS: ONTAP cluster discovery

|Console Agent to AI Data Engine
|80, 443, 8080, 9000
|TCP
|Bidirectional
|Communication between Console Agent and AI Data Engine

|AI Data Engine to ONTAP (NFS)
|111, 2049
|TCP/UDP
|To storage
|NFS data source access

|AI Data Engine to ONTAP (CIFS/SMB)
|139, 445
|TCP/UDP
|To storage
|CIFS/SMB data source access

|AI Data Engine to Active Directory
|389, 636, 3268, 3269
|TCP/UDP (389)
|Outbound
|LDAP/LDAPS: user authentication and CIFS scanning

|===

=== Outbound internet access

For an online installation, the following endpoints must be reachable from the AI Data Engine host:

[cols="2,2,1",options="header"]
|===
|Endpoint |Purpose |Scope

|`api.console.netapp.com`
|NetApp Console API
|Both

|`582244788873.dkr.ecr.us-east-1.amazonaws.com`
|NetApp container registry (images and Helm charts)
|Both

|`get.k3s.io`
|k3s download
|Lite only

|`get.helm.sh`
|Helm download
|Lite only

|===

Verify that DNS resolution for these endpoints is working from the AI Data Engine host before you begin deployment.

=== Additional prerequisites

* Root or sudo access on the target VM to run the installer

== AIDE Enterprise requirements

* RKE2 v1.36.x or later
* A configured StorageClass available on the cluster
* An NFS server with an exported path for the AIDE config volume
* kubectl access with cluster-admin privileges on the machine from which you run the installer
