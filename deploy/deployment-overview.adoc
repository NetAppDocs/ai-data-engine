= Learn about AI Data Engine deployment
:icons: font
:imagesdir: ../media/

[.lead]
AI Data Engine supports two deployment modes: AIDE Lite for a single-VM deployment and AIDE Enterprise for a Kubernetes-based deployment. Choose the mode that matches your environment size and infrastructure.

== AIDE Lite

AIDE Lite is a single-node deployment suitable for evaluation and small-to-mid-market workloads. It is the recommended starting point for most deployments.

== Deployment process

NetApp Console does not provision the infrastructure for AI Data Engine. You prepare a Linux machine that meets the requirements, then run an installation command that bootstraps the Kubernetes runtime and deploys the AI Data Engine stack automatically. Deployment typically completes within 15 minutes.

== Choosing a deployment mode

Consider these factors when choosing a deployment mode:

* *AIDE Lite*: recommended for evaluation, proof of concept, and small-to-mid-market production deployments. No Kubernetes expertise is required; the installer provisions k3s automatically.
* *AIDE Enterprise*: recommended for mid-market and enterprise production deployments that require high availability, scalability, or a customer-managed RKE2 cluster.
