= Learn about AI Data Engine deployment
:icons: font
:imagesdir: ../media/

[.lead]
Deploy AI Data Engine as an AIDE single-node deployment, which installs on a single Linux VM. If your environment requires Kubernetes-based high availability at large scale, you can deploy an AIDE multi-node deployment instead.

== AIDE single-node deployment

An AIDE single-node deployment installs on a single Linux VM. You don't need Kubernetes expertise because the installer provisions k3s automatically.

An AIDE single-node deployment is available in three sizes — Small, Medium, and Large — for environments up to approximately 200 million, 1 billion, and 3 billion files respectively. For full VM sizing and OS requirements, refer to link:aide-requirements.html[AIDE requirements]. These sizes are recommended baselines, not hard limits; see link:aide-requirements.html#flexible-sizing-single-node[flexible sizing guidelines] for what drives sizing and how to scale further.

== AIDE multi-node deployment

Deploy an AIDE multi-node deployment if your environment requires high availability, fault tolerance, rolling upgrades, or horizontal scaling beyond the largest single-node deployment size. An AIDE multi-node deployment runs as a multi-node Kubernetes cluster on a customer-provisioned and managed RKE2 cluster.

An AIDE multi-node deployment is available in three sizes — Small, Medium, and Large — for environments up to approximately 1 billion, 3 billion, and 6 billion files respectively. For full node sizing and cluster requirements, refer to link:aide-requirements.html[AIDE requirements]. These sizes are recommended baselines, not hard limits: environments exceeding 6 billion files are supported through horizontal scale-out. See link:aide-requirements.html#flexible-sizing-multi-node[flexible sizing guidelines] for details.

== Deployment process

You can deploy AI Data Engine directly from NetApp Console. Go to *AI data hub > AI Data Engine* and deploy AI Data Engine. Use the wizard and choose a deployment type and run the installation command in an environment that meets the link:aide-requirements.html[AIDE requirements].

NetApp Console doesn't provision the infrastructure for AI Data Engine. You prepare a Linux machine or cluster that meets the requirements, then copy the pre-generated installation command from NetApp Console and run it on the target host. The command bootstraps the runtime and deploys the AI Data Engine stack automatically. During installation, the installer prompts you to confirm the target host IP address and user ID before the install proceeds.

Single-node deployments typically complete within 45 minutes. Multi-node deployments typically complete within 30 minutes. The installer includes built-in timeouts and retries to handle transient issues while components start.
