= Learn about AI Data Engine deployment
:icons: font
:imagesdir: ../media/

[.lead]
AI Data Engine supports two deployment modes: AIDE Lite for a single-VM deployment and AIDE Enterprise for a Kubernetes-based deployment. Choose the mode that matches your environment size and infrastructure.

== AIDE Lite

AIDE Lite is a single-node deployment suitable for evaluation and small-to-mid-market workloads. It is the recommended starting point for most deployments.

AIDE Lite is available in three sizes — Small, Medium, and Large — for environments up to approximately 200 million, 1 billion, and 3 billion files respectively. For full VM sizing and OS requirements, see link:requirements.html[Requirements].

== AIDE Enterprise

AIDE Enterprise deploys as a multi-node Kubernetes cluster on infrastructure you provision and manage. It is designed for environments that require high availability and enterprise-scale performance.

AIDE Enterprise is available in three sizes — Small, Medium, and Large — for environments up to approximately 1 billion, 3 billion, and 6 billion files respectively. For full node sizing and cluster requirements, see link:requirements.html[Requirements].

== Deployment process

NetApp Console does not provision the infrastructure for AI Data Engine. You prepare a Linux machine that meets the requirements, then copy the pre-generated installation command from NetApp Console and run it on the target host. The command bootstraps the Kubernetes runtime and deploys the AI Data Engine stack automatically. Deployment typically completes within 15 minutes.

|===
| |AIDE Lite |AIDE Enterprise

|Best for

|Deployment model
|Single Linux VM
|Multi-node Kubernetes cluster

|High availability
|No
|Yes

|No
|Yes

|Horizontal scaling
|No
|Yes

|Rolling upgrades
|No
|Yes

|Air-gapped install
|Yes
|Yes

|Scan rate
|Up to 50 million files/day
|Up to 250 million files/day

|===

* *AIDE Lite*: No Kubernetes expertise is required. The installer provisions k3s automatically.
* *AIDE Enterprise*: Requires a customer-provisioned and managed RKE2 cluster.
