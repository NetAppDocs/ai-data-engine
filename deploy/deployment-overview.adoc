= Learn about AI Data Engine deployment
:icons: font
:imagesdir: ../media/

[.lead]
Deploy AI Data Engine as AIDE Lite, a single-VM installation. If your environment requires Kubernetes-based high availability at large scale, you can deploy AIDE Enterprise instead.

== AIDE Lite

AIDE Lite installs on a single Linux VM. No Kubernetes expertise is required as the installer provisions k3s automatically.

AIDE Lite is available in three sizes — Small, Medium, and Large — for environments up to approximately 200 million, 1 billion, and 3 billion files respectively. For full VM sizing and OS requirements, refer to link:aide-requirements.html[AIDE requirements].

== AIDE Enterprise

Deploy AIDE Enterprise if your environment requires high availability, fault tolerance, rolling upgrades, or horizontal scaling beyond AIDE Lite's largest size. AIDE Enterprise deploys as a multi-node Kubernetes cluster on a customer-provisioned and managed RKE2 cluster.

AIDE Enterprise is available in three sizes — Small, Medium, and Large — for environments up to approximately 1 billion, 3 billion, and 6 billion files respectively. For full node sizing and cluster requirements, refer to link:aide-requirements.html[AIDE requirements].

== Deployment process

NetApp Console does not provision the infrastructure for AI Data Engine. You prepare a Linux machine that meets the requirements, then copy the pre-generated installation command from NetApp Console and run it on the target host. The command bootstraps the Kubernetes runtime and deploys the AI Data Engine stack automatically. Deployment typically completes within 15 minutes.
