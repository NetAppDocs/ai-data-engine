= Deploy AI Data Engine — Lite
:icons: font
:imagesdir: ../media/

[.lead]
Deploy AIDE Lite from NetApp Console using the deployment wizard. The wizard guides you through selecting your installation location, choosing a configuration size, and running the install command on your target host.

.Before you begin
* Review link:requirements.html[requirements] and confirm your environment meets all prerequisites.
* You must have Platform Admin permissions in NetApp Console.

.Steps
. In NetApp Console, navigate to *Governance* > *AI Data Engine*.
+
The AI Data Engine landing page appears.

. Click *Deploy NetApp AI Data Engine*.
+
The deployment wizard opens with the header *AI Data Engine deployment*.

. In Step 1, select your installation location:
+
* *Cloud environment*: deploy in AWS, Azure, or Google Cloud. The system prepares a virtual machine in your selected cloud environment.
* *On premises*: install AI Data Engine on a local virtual machine in your on-premises environment.

. Click *Next*.

. In Step 2, select your configuration size:
+
* *Small*: recommended for environments with up to approximately 200 million files.
* *Medium*: recommended for environments with up to approximately 1 billion files.
* *Large*: recommended for environments with up to approximately 3 billion files.
+
// RESEARCH NEEDED: Confirm step numbering against current Figma — size selection may be numbered differently in the wizard.

. Click *Next*.

. In Step 3, copy the install command displayed in the wizard and run it on your target host:
+
[source,bash]
----
sudo ./install.sh -a account-XXXXX -c <token>
----
+
// RESEARCH NEEDED: Confirm command format — engineering docs reference `./install-lite.sh --flavor <small|medium|large> --user-token <token>`.
+
After the command runs, the wizard transitions automatically to the progress screen.

. Monitor the progress screen while AI Data Engine completes the following steps:
.. Deploying the AI Data Engine
.. Verifying connectivity to NetApp Console and the Internet
.. Initializing the AI Data Engine

. When the success screen appears and displays *"AI Data Engine deployed,"* click *Continue to configuration*.

.Result
AI Data Engine is deployed and connected to NetApp Console. You can now link:../data-sources/connect-data-source.html[connect an ONTAP cluster] to start scanning.

If the installation fails, see link:troubleshoot-deploy.html[Troubleshoot deployment].

To deploy AI Data Engine Enterprise instead, see link:deploy-enterprise.html[Deploy AI Data Engine — Enterprise].
