= Deploy AI Data Engine as a multi-node deployment
:icons: font
:imagesdir: ../media/

[.lead]
Deploy AIDE as a multi-node deployment from NetApp Console using the deployment wizard. The wizard guides you through selecting your installation location, choosing a configuration size, and running the install command against your Kubernetes cluster.

.Before you begin

* You have _Organization admin_ or greater permissions in NetApp Console.
* Your Kubernetes cluster meets the multi-node prerequisites described in link:multi-node-prerequisites.html[AIDE multi-node deployment prerequisites] and link:aide-requirements.html[AIDE requirements].
* Sudo (or root) permissions are required on the machine from which you run the install command.
* An NFS server with an exported path is available and reachable from the cluster for the AIDE config volume.
* A NetApp Console agent https://docs.netapp.com/us-en/console-setup-admin/concept-agent-install-options.html#agent-console-deploy[is deployed^] and reachable from the cluster nodes. The Console Agent IP is required to run the install command.
* kubectl is available on the machine from which you run the install command, with cluster-admin access to the target cluster.
* The target Kubernetes namespace (default `aide`) already exists on the cluster before you run the install command.
* A configured StorageClass (default name: `aide-sc`) is available on the cluster and used for AIDE's stateful backing services.
* If your environment uses an outbound proxy, see link:configure-proxy.html[Configure a proxy].

.Steps
. In NetApp Console, navigate to *AI data hub* > *AI Data Engine*.
+
The AI Data Engine landing page appears.

. Select *Deploy AI Data Engine*.
. Select the *Multi-node* deployment option and select *Next*.
. Select your configuration size:
+
* *Small*: recommended for environments with up to approximately 1 billion files.
* *Medium (Default)*: recommended for environments with up to approximately 3 billion files.
* *Large*: recommended for environments with up to approximately 6 billion files.
+
These sizes are recommended baselines, not hard limits. An AIDE multi-node deployment requires custom sizing with NetApp for environments beyond 6 billion files; see link:aide-requirements.html#flexible-sizing-multi-node[flexible sizing guidelines] for details.

. Copy the install command displayed in the wizard to an editor.
+

The install command downloads the installer from a content delivery network (CDN) and then runs it.
+
* If you don't use a proxy: Run the install command as copied. No additional steps are required.
* If you use a proxy or your environment restricts internet access: The download step doesn't use a proxy. Download the installer by using your standard methods, transfer it to the machine from which you run the install command, and then run the installer from that machine.

. If you use a proxy, remove `--no-proxy` from the install command if it's present, and add the proxy options. See link:configure-proxy.html[Configure a proxy].
+
NOTE: If the command doesn't include `--no-proxy`, the installer asks whether to configure an outbound proxy when you run it.

. Run the install command from your target host with kubectl access to your Kubernetes cluster.
+
NOTE: Installation takes about 30 minutes to complete. Timeouts and retries might occur, and this is normal.

. When prompted, confirm the host IP address and user ID to continue the installation.
. Monitor the progress screen until the success screen appears and displays "AI Data Engine deployed".

.Result
Your AI Data Engine multi-node deployment is deployed and connected to NetApp Console. You can now link:../data-sources/connect-data-source.html[connect a data source] to start scanning.
