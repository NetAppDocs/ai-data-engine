= Deploy AI Data Engine Enterprise
:icons: font
:imagesdir: ../media/

[.lead]
Deploy AIDE Enterprise from NetApp Console using the deployment wizard. The wizard guides you through selecting your installation location, choosing a configuration size, and running the install command against your RKE2 cluster.

.Before you begin

* You must have _Organization admin_ or greater permissions in NetApp Console.
* Review link:aide-requirements.html[AIDE requirements] and confirm your RKE2 cluster meets Enterprise node prerequisites.
* An NFS server with an exported path must be available and reachable from the cluster for the AIDE config volume.
* A NetApp Console agent https://docs.netapp.com/us-en/console-setup-admin/concept-agent-install-options.html#agent-console-deploy[must be deployed^] and reachable from the cluster nodes. The Console Agent IP is required to run the install command.
* kubectl must be available on the machine from which you run the install command, with cluster-admin access to the target cluster.


.Steps
. In NetApp Console, navigate to *Governance* > *AI Data Engine*.
+
The AI Data Engine landing page appears.

. Click *Deploy AI Data Engine*.
. Read and accept terms and continue.
. Select your configuration size:
+
* *Small*: recommended for environments with up to approximately 1 billion files.
* *Medium*: recommended for environments with up to approximately 3 billion files.
* *Large*: recommended for environments with up to approximately 6 billion files.

. Click *Next*.

. Copy the preconfigured install command displayed in the wizard and run it from a host with kubectl access to your RKE2 cluster:
// The install command shown here may require command-line customizations after the wizard behavior is confirmed.
// [source,bash]
// ----
// sudo ./install-enterprise.sh \
//   --flavor <small> \
//   --registry <registry-host> \
//   --nfs-server <nfs-server-host> \
//   --nfs-data-share <nfs-export-path> \
//   --storage-class <storage-class-name> \
//   --account-id <account-id> \
//   --organization-id <organization-id> \
//   --agent-id <agent-id> \
//   --cm-host <console-agent-ip> \
//   --user-token <token>
// ----
// RESEARCH NEEDED: Confirm this is the exact command format shown in the wizard UI.

. Monitor the progress screen until the success screen appears and displays *"AI Data Engine deployed"*. Click *Continue to configuration*.

.Result
AI Data Engine Enterprise is deployed and connected to NetApp Console. You can now link:../data-sources/connect-data-source.html[connect a data source] to start scanning.
