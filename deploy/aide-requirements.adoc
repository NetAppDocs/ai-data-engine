=== Additional prerequisites

* Root or sudo access on the target VM to run the installer.
* 1 GbE minimum network connection (10 GbE required for Large deployments).
* bash 4.0 or later, curl, and tar available on the target host.
* The installer automatically downloads and bootstraps `k3s`, `helm`, `kubectl`, and `jq`. Pre-installing these tools on the target VM is not required.
* Ports 6443 (TCP), 10250 (TCP), and 8472 (UDP) must be free on the host before the installer starts. If a host firewall (`firewalld` on RHEL or `ufw` on Ubuntu) is active, allow these ports and the k3s pod CIDR (`10.44.0.0/16`) and service CIDR (`10.45.0.0/16`) before running the installer. Refer to your OS firewall documentation for the required commands.
* On RHEL systems running SELinux in Enforcing mode, the installer automatically configures the required SELinux policy packages. No manual SELinux configuration is needed.
* If your environment requires an outbound proxy to reach the endpoints listed above, have the proxy host, port, scheme, and credentials (if required) ready; the installer prompts for this during setup.

== AIDE Enterprise requirements

* RKE2 v1.34 or later (v1.36.x recommended)
* The installer host automatically downloads and bootstraps `helm`, `kubectl`, and `jq` via `--tools-dir`. Pre-installing these tools on the management machine is not required.
* A configured StorageClass (default name `aide-sc`) available on the cluster, used for AIDE's stateful backing services
* An NFS server with at least one exported path, used for the AIDE configuration data volume and shared index snapshots
* kubectl access with cluster-admin privileges on the machine from which you run the installer
* A target Kubernetes namespace (default `aide`) already exists on the cluster; the installer does not create it
* If your environment requires an outbound proxy, have the proxy host, port, scheme, and credentials (if required) ready; the installer prompts for this during setup.
// RESEARCH NEEDED: Confirm the proxy prompt/flags are part of the Console-wizard-generated install command customers use, not just an advanced/CI-only path, before publishing.

NOTE: NVMe or high-performance SSD storage is recommended for all Enterprise node deployments.
