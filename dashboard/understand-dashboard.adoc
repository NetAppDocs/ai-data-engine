= Learn about the AI Data Engine dashboard
:icons: font
:imagesdir: ../media/

[.lead]
Before you investigate individual files, use the Overview to see how much of your storage is wasted and where. The dashboard is your entry point into AI Data Engine: it tells you where to look, and Investigation is where you confirm and act.

For example, a storage administrator responding to a capacity alert can see that a significant portion of scanned storage is cold data, then drill into the highest-impact system to start investigating immediately.

From the AI Data Engine left navigation, click *Overview*. The *System* and *System type* filters at the top of the page control dashboard scope, reflecting storage systems that have been registered through the Console Agent and enabled for scanning. If a storage system does not appear in the filter list, see link:../data-sources/connect-data-source.html[Configure and manage scanned systems].

== What the dashboard tells you

The Overview page shows how much storage exists across your environment, how much of it is wasted (cold or stale), and where that waste is concentrated. The summary panel and chart give you the numbers; the resource table tells you where to focus.

== Summary panel

The summary panel at the top of the page provides workspace-level metrics:

[cols="1,2",options="header"]
|===
|Metric |Description

|Storage resources scanned
|Total count of storage resources scanned across all connected systems.

|Storage growth rate
|Average daily storage growth across scanned resources (for example, 94 GiB/day).

|Reclaimable storage
|Total storage identified as reclaimable: the combined total of cold and stale data.

|Cold data
|Data that has not been accessed in one or more years.

|Stale data
|Data that has not been modified in three or more years.

|===

== Active versus reclaimable storage chart

The *Active versus reclaimable storage* chart shows the proportion of active data compared to cold and stale data across your scanned resources. Use this chart to assess overall storage efficiency at a glance.

== Identify storage optimization opportunities

Use the summary panel and chart to prioritize storage optimization opportunities:

* Start with the resource that has the largest reclaimable size, not the largest total size. A small system that is mostly cold data is often a better first target than a large system that is mostly active.
* Look for clusters of waste rather than isolated files. Tens of terabytes of stale data on one resource justifies an investigation; a single stale file does not.
* Compare storage growth rate against reclaimable storage. A system with high growth and low reclaimable storage indicates active demand, not waste, and is a lower cleanup priority.

== Drill down from a dashboard finding into investigation

After you identify a resource worth investigating, use the *Top storage resources by reclaimable storage* table to move from the overview to the details.

This table lists your scanned storage resources ranked by reclaimable storage:

[cols="1,2",options="header"]
|===
|Column |Description

|Storage resource
|The name of the scanned storage resource.

|Type
|The resource type, such as External file share, Cloud Volumes ONTAP, S3, or ONTAP.

|Reclaimable size
|The amount of storage identified as reclaimable on this resource.

|File count
|The number of reclaimable files on this resource.

|===

Click *Investigate* in any row to open the link:../investigate/investigate-data.html[Investigation] view filtered to that resource.

== Refresh and explore further

* Click *Refresh* to update the page with the latest scan data. The last-updated timestamp displays below the page header.
* Click *Explore cost optimization recommendations* to view additional recommendations based on your scan data.
