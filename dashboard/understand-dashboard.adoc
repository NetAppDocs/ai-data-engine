= Review the Overview page
:icons: font
:imagesdir: ../media/

[.lead]
Use the Overview to quickly assess storage health across your entire environment before deciding where to focus your investigation. For example, a storage administrator responding to a capacity alert can see at a glance that a significant portion of scanned storage is cold data, then click into the highest-impact system to start investigating immediately.

== Navigate to Overview

From the AI Data Engine left navigation, click *Overview*.

The *System* and *System type* filters at the top of the page control dashboard scope. These filters reflect storage systems that have been registered through the Console Agent and enabled for scanning. If a storage system does not appear in the filter list, see link:../data-sources/connect-data-source.html[Configure and manage scanned systems].

== Summary panel

The summary panel at the top of the page provides workspace-level metrics:

[cols="1,2",options="header"]
|===
|Metric |Description

|Storage resources scanned
|Total count of storage resources scanned across all connected systems.

|Storage growth rate
|Average daily storage growth across scanned resources (for example, 94 GiB/day).

|Reclaimable storage
|Total storage identified as reclaimable: the combined total of cold and stale data.

|Cold data
|Data that has not been accessed in one or more years.

|Stale data
|Data that has not been modified in three or more years.

|===

== Active versus reclaimable storage chart

The *Active versus reclaimable storage* chart shows the proportion of active data compared to cold and stale data across your scanned resources. Use this chart to assess overall storage efficiency at a glance.

== Top storage resources by reclaimable storage

This table lists your scanned storage resources ranked by reclaimable storage:

[cols="1,2",options="header"]
|===
|Column |Description

|Storage resource
|The name of the scanned storage resource.

|Type
|The resource type, such as External file share, Cloud Volumes ONTAP, S3, or ONTAP.

|Reclaimable size
|The amount of storage identified as reclaimable on this resource.

|File count
|The number of reclaimable files on this resource.

|===

Click *Investigate* in any row to open the link:../investigate/investigate-data.html[Investigation] view filtered to that resource.

== Refresh and explore further

* Click *Refresh* to update the page with the latest scan data. The last-updated timestamp displays below the page header.
* Click *Explore cost optimization recommendations* to view additional recommendations based on your scan data.
