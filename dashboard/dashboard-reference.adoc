= Dashboard reference
:icons: font
:imagesdir: ../media/

[.lead]
This reference describes each metric and section on the AI Data Engine Overview page.

== Summary panel

[cols="1,2",options="header"]
|===
|Metric |Description

|Storage resources scanned
|Total count of storage resources scanned across all connected systems.

|Storage growth rate
|Average daily storage growth across scanned resources (for example, 94 GiB/day).

|Reclaimable storage
|Total storage identified as reclaimable — the combined total of cold and stale data.

|Cold data
|Storage consumed by data that has not been accessed in one or more years.

|Stale data
|Storage consumed by data that has not been modified in three or more years.

|===

== Active versus reclaimable storage chart

A chart showing the proportion of active data compared to cold and stale data across all scanned resources. Use this to assess overall storage efficiency.

== Top storage resources by reclaimable storage

|Reclaimable size
|The amount of storage identified as reclaimable on this resource.

|File count
