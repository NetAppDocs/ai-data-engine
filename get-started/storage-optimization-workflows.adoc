= Explore storage optimization workflows in AI Data Engine
:icons: font
:imagesdir: ../media/

[.lead]
These AI Data Engine workflows take you from identifying a storage problem on the dashboard through investigation and action to an ongoing monitoring policy. Each workflow follows the same path: dashboard, investigate, act, and save as a policy.

== Identify and act on cold data

.Scenario
You notice on the dashboard that a storage resource has a large amount of data flagged as cold. Cold files haven't been accessed within the configured cold data threshold, which defaults to one year and is configurable in *Configuration* > *Settings*.

.Steps
. From link:../investigate/understand-dashboard.html[the dashboard], identify the resource with the highest concentration of cold data and select *Investigate*.
. In link:../investigate/investigate-unstructured.html[Investigation], confirm the resources using the *Last accessed* filter set to match your configured cold data threshold (default: *1+ year*).
. Review the results to decide link:../investigate/take-actions.html[whether to tag, archive, or delete] the matching files.
. If these resources are worth monitoring on an ongoing basis, link:../policies/create-policy.html[save the filter set as a policy] so you are notified as new files go cold.

== Identify and act on stale data

.Scenario
Files that are still occasionally accessed but haven't been modified in years are classified as stale when they fall outside your organization's stale threshold (default: three years since last access or modification). 

NOTE: This threshold is configurable in *Configuration* > *Settings*.

.Steps
. From link:../investigate/understand-dashboard.html[the dashboard], identify a resource with significant stale data.
. In link:../investigate/investigate-unstructured.html[Investigation], apply the *Last modified* filter set to your stale threshold (default *3+ years*).
. Review the results to decide link:../investigate/take-actions.html[whether to tag, archive, or delete] the matching files.
. link:../policies/create-policy.html[Save the filter set as a policy] to track these resources across subsequent scans.

== Manage data retention compliance

.Scenario
Your organization requires that files older than a certain age are reviewed for retention. The default retention threshold in AI Data Engine is seven or more years since file creation. You can adjust this threshold to match your organization's compliance and retention policies.

NOTE: This threshold is configurable in *Configuration* > *Settings*.

.Steps
. In link:../investigate/investigate-unstructured.html[Investigation], apply the *Last created* filter set to your retention threshold (default *7+ years*).
. Review the results with the relevant stakeholders before acting. Retention-flagged files are often monitored rather than automatically deleted.
. link:../policies/create-policy.html[Create a policy] with a monitor-only or email notification action so you are alerted as new files meet the retention threshold, rather than acting on these resources once.

== Find and eliminate duplicate files

.Scenario
Multiple identical copies of the same files exist across volumes or shares, a common issue in environments with backup jobs, data migrations, or shared project folders.

.Steps
. In link:../investigate/investigate-unstructured.html[Investigation], select *Add filter* and then select *Duplicates*.
. Review the results. Files listed have one or more identical copies elsewhere in the catalog.
. Select files to act on and choose link:../investigate/take-actions.html[an action]. Archive or delete confirmed duplicates that have an original copy elsewhere.
. link:../policies/create-policy.html[Save the filter as a policy] to track duplicate accumulation over time and receive notifications when the count increases.

== Target cleanup by data owner

.Scenario
Data meeting your organization's cold and stale thresholds is distributed across many owners. Identifying which data owners hold the most files in these categories can help you prioritize cleanup.

.Steps
. From link:../investigate/understand-dashboard.html[the dashboard], locate the _Top data owners by reclaimable storage_ table.
. Select an owner row to open link:../investigate/investigate-unstructured.html[Investigation] filtered to that owner's files.
. Review the results and decide link:../investigate/take-actions.html[whether to tag, archive, or delete] files.
. link:../policies/create-policy.html[Save the filter set as a policy] to monitor how that owner's potentially reclaimable data changes over time.
