= Learn about AI Data Engine
:icons: font
:imagesdir: ../media/

[.lead]
AI Data Engine is a metadata intelligence service that gives you visibility into the unstructured data stored on your storage systems. By scanning your storage systems and cataloging file system metadata, AI Data Engine helps you identify storage optimization opportunities, investigate your data, and enforce governance policies, without moving or copying data.

== What AI Data Engine does

AI Data Engine scans connected storage systems to extract file system metadata and builds a continuously updated catalog. From this catalog, you can:

* View storage optimization insights on a dashboard, including cold data, file type distribution, duplicate files, and potential space savings by volume
* Investigate your data using flexible metadata filters to build targeted data grouping
* Create policies that save investigation criteria as reusable rules
* Take actions on data: tagging, archiving, or deleting files that match policy criteria

== Storage optimization and data governance

AI Data Engine is focused on storage optimization and data lifecycle management for unstructured file data stored on your storage systems.

== Who uses AI Data Engine

AI Data Engine is designed for the following users:

* *Storage administrators* who need to identify and reclaim storage space, stale data, cold files, and duplicates, to reduce costs.
//* *Data stewards* who need to govern data quality and enforce lifecycle policies across the organization.
* *IT operations teams* who need a central view of what unstructured data exists across their storage environment.

== Where AI Data Engine lives

AI Data Engine is accessed through NetApp Console, under *Governance > AI Data Engine*. You deploy it as a software instance on Linux infrastructure you manage, either a virtual machine in your cloud account or a machine in your on-premises environment. Two editions are available: *Lite* for single-node deployments and *Enterprise* for multi-node Kubernetes clusters.
