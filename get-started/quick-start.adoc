= Quick start for AI Data Engine
:icons: font
:imagesdir: ../media/

[.lead]
Get AI Data Engine up and running by deploying the service, connecting your storage systems, and starting your first investigation.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png[One] Review requirements
[role="quick-margin-para"]
Review the link:../deploy/aide-requirements.html[AIDE requirements] and link:../deploy/deployment-overview.html[learn about deployment modes] to determine whether to install AIDE Lite or AIDE Enterprise.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png[Two] Deploy AI Data Engine
[role="quick-margin-para"]
Deploy link:../deploy/deploy-aide-lite.html[AIDE Lite] or link:../deploy/deploy-enterprise.html[AIDE Enterprise] from NetApp Console. The setup page guides you through selecting your installation location and configuration size and running the install command.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png[Three] Connect a data source
[role="quick-margin-para"]
link:../data-sources/connect-data-source.html[Connect a data source] to begin scanning. AI Data Engine catalogs file system metadata from the storage systems you specify.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png[Four] Explore your data
[role="quick-margin-para"]
Open the link:../investigate/understand-dashboard.html[dashboard] to see storage optimization insights, or go to link:../investigate/investigate-data.html[Investigation] to search and filter your metadata directly.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-5.png[Five] Create a policy
[role="quick-margin-para"]
link:../policies/create-policy.html[Save your investigation filters as a policy] to monitor files that match the same criteria over time. You can configure a policy to send a notification, permanently delete matching files, or track the results.
