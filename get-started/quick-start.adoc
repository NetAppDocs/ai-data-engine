= Quick start for AI Data Engine
:icons: font
:imagesdir: ../media/

[.lead]
Get AI Data Engine up and running in a few steps.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png[One] Review requirements and choose your deployment model
[role="quick-margin-para"]
Review the link:../deploy/requirements.html[requirements] and decide whether to deploy link:../deploy/deployment-overview.html[AIDE Lite or AIDE Enterprise] based on your environment size and infrastructure.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png[Two] Deploy AI Data Engine
[role="quick-margin-para"]
link:../deploy/deploy-aide-lite.html[Run the deployment wizard] from NetApp Console. The wizard guides you through selecting your installation type and running the install command.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png[Three] Connect a storage system
[role="quick-margin-para"]
link:../data-sources/connect-data-source.html[Connect a storage system] to begin scanning. AI Data Engine catalogs file system metadata from the volumes you specify.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png[Four] Explore your data
[role="quick-margin-para"]
Open the link:../dashboard/understand-dashboard.html[dashboard] to see storage optimization insights, or go to link:../investigate/investigate-data.html[Investigation] to search and filter your metadata directly.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-5.png[Five] Create a policy
[role="quick-margin-para"]
link:../policies/create-policy.html[Save your investigation filters as a policy] to reuse them or to automate an action, such as tagging or archiving, on files that match the criteria.
