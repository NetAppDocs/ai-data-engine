= Manage users and roles in AI Data Engine
:icons: font
:imagesdir: ../media/

[.lead]
Before your team starts using AI Data Engine, make sure each user has the right level of access. AI Data Engine uses role-based access control (RBAC) to define what each user can view and do within the product.

Roles are assigned through NetApp Console organization settings. AI Data Engine supports two roles at general availability.

== Available roles

=== AI Data Engine administrator

The AI Data Engine administrator role provides full access to all AI Data Engine capabilities. NetApp recommends assigning this role to no more than two or three users per deployment.

=== AI Data Engine viewer

The AI Data Engine viewer role provides read-only access to AI Data Engine. Viewers can view information and export reports, but cannot modify settings or execute actions.

== Assign a role to a user

Roles are assigned in NetApp Console, not within AI Data Engine itself.

.Steps

. From NetApp Console, go to *Members*.
. Do one of the following:
* To add a new user, select *Add user* and enter the user's email address.
* To update an existing user, select the user from the list.
. Select the organization, folder, or project, and then choose the *Data Service* category.
. Assign the *AI data engine administrator* or *AI data engine viewer* role.
. Save your changes.

The user receives an email invitation and can access AI Data Engine after accepting it.
