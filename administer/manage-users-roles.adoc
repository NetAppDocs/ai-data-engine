= Manage users and roles in AI Data Engine
:icons: font
:imagesdir: ../media/

[.lead]
Before your team starts using AI Data Engine, make sure each person has the right level of access. AI Data Engine uses role-based access control (RBAC) to define what each user can view and do, so users who only need to view the dashboard can't delete data, and users responsible for cleanup have the access they need.

== Available roles

=== Storage Ops

Designed for storage administrators who manage storage optimization. Storage Ops users can execute storage actions (archive, delete), create and manage policies and filters, view all dashboards, and manage scan tasks.

=== Read-Only

Can view dashboards only. Read-Only users cannot investigate, create policies, or take actions on data.
