= Manage users and roles in AI Data Engine
:icons: font
:imagesdir: ../media/

[.lead]
AI Data Engine uses role-based access control (RBAC) to define what each user can view and do within the product. Before your team starts using AI Data Engine, assign each user the role that matches their required level of access.

You assign roles through NetApp Console organization settings. AI Data Engine supports two roles at general availability.

== Available roles

=== AI Data Engine administrator

The AI Data Engine administrator role provides full access to all AI Data Engine capabilities. NetApp recommends assigning this role to no more than two or three users per deployment.

=== AI Data Engine viewer

The AI Data Engine viewer role provides limited access to AI Data Engine. Viewers can view information, export reports, tag files, and create monitor-only policies, but cannot modify settings or perform file actions such as archive, copy, or delete.

== Assign a role to a user

You assign roles in NetApp Console, not within AI Data Engine itself.

.Steps

. From NetApp Console, go to *Members*.
. Do one of the following:
* To add a new user, select *Add user* and enter the user's email address.
* To update an existing user, select the user from the list.
. Select the organization, folder, or project, and then choose the *Data Service* category.
. Assign the *AI data engine administrator* or *AI data engine viewer* role.
. Save your changes.

The user receives an email invitation and can access AI Data Engine after accepting it.
