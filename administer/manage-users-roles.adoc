= Manage users and roles
:icons: font
:imagesdir: ../media/

[.lead]
AI Data Engine uses role-based access control (RBAC) to define what each user can view and do. Assign roles to users based on their responsibilities within your organization.

== Available roles

=== Storage Ops

Designed for storage administrators who manage storage optimization. Storage Ops users can execute storage actions (archive, delete), create and manage policies and filters, view all dashboards, and manage scan tasks.

=== Read-Only

Can view dashboards only. Read-Only users cannot investigate, create policies, or take actions on data.
