= Configure cold and stale data thresholds in AI Data Engine
:icons: font
:imagesdir: ../media/

[.lead]
AI Data Engine classifies files as cold or stale based on time thresholds you define. These thresholds affect which data appears in dashboard summaries, which files appear when you apply cold or stale filters in Investigation, and which files policies target. Set thresholds that match your organization's data classification and retention practices, and to identify data you consider important to monitor.

== What is cold and stale data?

Cold data:: Files that have not been accessed within the configured cold data threshold. Cold data is a key metric your organization can use to identify storage that could be optimized according to your retention and business policies.

Stale data:: Files that have not been accessed or modified within the configured stale data threshold. Stale data captures files that see occasional access but no recent modification, and your organization can monitor or manage according to your policies.

NOTE: The default threshold values are product defaults provided as a starting point. They do not represent legal, compliance, or industry-standard retention periods. Set thresholds that reflect your organization's specific policies and requirements.

Changes to either threshold take effect after the next scan cycle completes.

== Configure the cold data threshold

.Before you begin
* You must have the _AI Data Engine administrator_ role.

.Steps
. From the AI Data Engine UI, select *Configuration*.
. Select *Settings*.
. Select *Edit* for *Cold data definition*.
. Set the file property to *Last Accessed* or *Last Modified*.
. Set the time threshold. The default is one year.
. Select *Save*.

== Configure the stale data threshold

.Before you begin
* You must have the _AI Data Engine administrator_ role.

.Steps
. From the AI Data Engine UI, select *Configuration*.
. Select *Settings*.
. Select *Edit* for *Stale data definition*.
. Set the file property to *Last Accessed* or *Last Modified*.
. Set the time threshold. The default is three years.
. Select *Save*.
