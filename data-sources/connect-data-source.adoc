= Connect a data source to AI Data Engine
:icons: font
:imagesdir: ../media/

[.lead]
Connect a storage system to AI Data Engine by completing the data source onboarding wizard. The wizard collects the connection details, scan scope, and scan settings for your source type. After you add the system, activate scanning to begin metadata collection.

.Before you begin

* Storage systems must first be discovered in NetApp Console using a Console Agent before they can be added to AI Data Engine. This applies to all supported storage types, including on-premises ONTAP clusters, Cloud Volumes ONTAP, Amazon FSx for NetApp ONTAP, Google Cloud NetApp Volumes, and Azure NetApp Files. For on-premises ONTAP clusters, see link:https://docs.netapp.com/us-en/storage-management-ontap-onprem/task-discovering-ontap.html[Discover on-premises ONTAP clusters] in the NetApp Console documentation. Direct discovery does not enable data services such as AI Data Engine.
* Verify that the network connections required for AI Data Engine to reach your data sources are open. See link:../deploy/aide-requirements.html[AI Data Engine requirements].

== Add a data source

.Steps
. From the AI Data Engine UI, click *Configuration*.
. On the *Scanned systems* tab, click *Add system*.
. Select a source type:
+
[cols="1,2",options="header"]
|===
|Source type |Description

|*File shares group*
|Add NFS or CIFS (SMB) file shares from the cloud or on-premises as a named group.

|*Database*
|Add a database server to scan selected schemas.

|*StorageGRID*
|Scan data from NetApp StorageGRID using the S3 protocol.

|===

. Enter the connection details for your source type:
+
[cols="1,3",options="header"]
|===
|Source type |Required details

|*File shares group*
|A name for the share group, then the share host and path details.

|*Database*
|Database type, host, port, and authentication credentials.

|*StorageGRID*
|System name, S3 endpoint URL, and S3 access key and secret key.

|===
//. Select the scan scope:
//+
//* *File shares group*: Select the share paths to include.
//* *Database*: Select the schemas to activate.
//* *StorageGRID*: Select the S3 buckets to include.
//
//. Configure scan settings.
// RESEARCH: Confirm the exact scan settings options in the V2 UI (scan frequency, path exclusions, depth limits).
//
//. Enable or disable content intelligence for this data source.
// RESEARCH: Confirm the exact UI label for the content intelligence toggle and what enabling it does.

. Review your selections and click *Confirm* to add the data source.

== Activate scanning

After you configure a data source, scanning does not start automatically. You must activate scanning for each system.

.Steps
. From the AI Data Engine UI, click *Configuration*.
. On the *Scanned systems* tab, locate the system you want to scan.
. Click *Activate scans*.

.Result

The system status updates in the Scanned systems tab to show that scanning is running. To monitor scan progress and verify that data resources are being indexed, see link:manage-data-sources.html[Manage data sources] and link:../monitor/monitor-scanning-health.html[Monitor scanning health].
