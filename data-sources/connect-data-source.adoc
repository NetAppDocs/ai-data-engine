= Configure and manage scanned systems in AI Data Engine
:icons: font
:imagesdir: ../media/

[.lead]
Add storage systems to AI Data Engine and review their scan status to ensure accurate, current metadata across your environment. For example, a storage administrator connecting a new storage system adds it here, then checks scan status to confirm volumes are being indexed before the team starts investigating data.

.Before you begin

* For the storage system to be accessible to AIDE, it must first be discovered in NetApp Console using a Console Agent. For on-premises ONTAP clusters, see link:https://docs.netapp.com/us-en/storage-management-ontap-onprem/task-discovering-ontap.html[Discover on-premises ONTAP clusters] in the NetApp Console documentation. Direct discovery does not enable data services such as AI Data Engine.

== Add a storage system

.Steps
. From the AI Data Engine UI, click *Configuration*.
. On the Scanned systems tab, click *Add system*.
. Follow the prompts to connect your storage system.

== Activate scanning on a storage system

After a storage system is added, scanning is not enabled automatically. You activate scans per system.

.Steps
. From the AI Data Engine UI, click *Configuration*.
. On the Scanned systems tab, locate the storage system you want to enable for scanning.
. Click *Activate scans*.

== View system details

Click a system row to open the detail view. The detail view shows:

* Status overview with scan progress
* Data container scan breakdown (running, completed, paused, errors)
* Options to *Pause* scanning or *Edit CIFS credentials*
* Option to *Enable access to DP volumes*
* Scan permission mode (for example, "Scan without write permissions")
