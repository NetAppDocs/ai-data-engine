= Configure and manage scanned systems
:icons: font
:imagesdir: ../media/

[.lead]
Add storage systems and monitor their scan health to ensure AI Data Engine has current, accurate metadata from across your environment. For example, a platform administrator onboarding a new environment adds each storage system here and checks the health monitor to confirm scans complete without errors before the team starts investigating data.

== Navigate to Configuration

From the AI Data Engine left navigation, click *Configuration*.

The Configuration page has three tabs: *Scanned systems*, *Health monitor*, and *Settings*.

== Scanned systems tab

The Scanned systems tab is the default view. The summary panel at the top shows:

[cols="1,2",options="header"]
|===
|Metric |Description

|Systems
|Total number of connected storage systems.

|Scanned storage resources
|Resources scanned out of the total available (for example, 214 / 360).

|Scans completed
|Count of storage resources with successfully completed scans.

|Scanning
|Count of storage resources currently being scanned.

|With errors
|Count of systems with scan errors.

|===

Use the filter bar to narrow the system list by *System type*, *Has errors*, or *Scanning status*.

The systems list displays each connected system with its name and type, scan status indicators (success and error counts), Console agent assignment, and any storage events or alerts.

== Add a storage system

.Steps
. On the Scanned systems tab, click *Add system*.
. Follow the prompts to connect your storage system.

== View system details

Click a system row to open the detail view. The detail view shows:

* Status overview with scan progress
* Data container scan breakdown (running, completed, paused, errors)
* Options to *Pause* scanning or *Edit CIFS credentials*
* Option to *Enable access to DP volumes*
* Scan permission mode (for example, "Scan without write permissions")
