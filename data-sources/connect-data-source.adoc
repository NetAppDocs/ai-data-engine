= Connect an ONTAP cluster
:icons: font
:imagesdir: ../media/

[.lead]
Connect an ONTAP cluster to AI Data Engine to make it available for metadata scanning. After you connect a cluster, AI Data Engine scans the cluster's file system metadata and makes it available in the dashboard and investigation views.

.Before you begin
* AI Data Engine must be link:../deploy/deploy-aide.html[deployed and connected to NetApp Console].
* NFS or CIFS/SMB must be enabled on the ONTAP cluster.
* Required network ports must be open between AI Data Engine and the ONTAP cluster. See link:../deploy/requirements.html[Requirements].

.Steps
// RESEARCH NEEDED (LOW): Replace the following placeholder steps with the verified UI flow for connecting a data source. Review the data source connection UI in Figma and the corresponding engineering spec.

. In NetApp Console, navigate to *Governance* > *AI Data Engine*.
. Click *Add data source* or the equivalent control.
. Enter the ONTAP cluster management IP address or hostname.
. Provide credentials with access to the file system.
. Select the volumes or shares to include in the scan.
. Click *Connect*.

.Result
AI Data Engine begins scanning the connected cluster. Initial scan time depends on the number of files. You can monitor scan progress from the dashboard.
