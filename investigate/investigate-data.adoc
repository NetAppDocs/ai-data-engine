= Investigate your data in AI Data Engine
:icons: font
:imagesdir: ../media/

[.lead]
When you need to understand what is consuming storage or find files ready for archival or deletion, search and filter metadata across all connected systems. For example, a storage administrator investigating unexpected capacity growth can filter by last-access time and file size to surface terabytes of VM snapshots that have not been touched in years, then act on those files directly.

== Navigate to Investigation

From the AI Data Engine UI, click *Investigation*.

You can also open Investigation from the Overview page by clicking *Investigate* in the Top storage resources table. Investigation opens with a filter pre-applied for that resource.

The Investigation view displays a summary count and total size of all unstructured items across connected systems (for example, "Unstructured items (400M) | 5.7 PiB").

== Find cold, stale, and at-risk files

Use date-based filters to identify reclaimable storage. The following table describes each filter, its default threshold, and what matching files represent.

[cols="1,1,2",options="header"]
|===
|Filter |Default threshold |What it identifies

|Last accessed
|365+ days
|Cold files that have not been accessed in a year or more. Strong candidates for archival or deletion.

|Last modified
|3+ years
|Stale files that have not been modified recently, even if still occasionally accessed.

|Last created
|7+ years
|Files that may be subject to your organization's retention review requirements.

|===

.Steps
. Click *Add filter*.
. Select a filter from the table above.
. Set the value to the appropriate threshold.

=== Refine results with additional filters

Combine any of the filters above with file size, path, system, tag, or policy filters to narrow the results further. For the complete list of available filters, see link:use-filters.html[Work with filters].

.Steps
. Click *Add filter*.
. Select a filter criterion and value.
. Repeat to add additional filters.

Applied filters appear as tags below the filter bar (for example, "Last accessed: 365+ days | File size: >5 GiB"). The results table and item count update each time you add a filter.

To clear all filters, click *Clear filters*.

== View investigation results

The results table shows files that match your applied filters. When filters are active, the header shows the filtered count and size (for example, "Unstructured items (250k / 400M) | 8.3 TiB | Filters applied (2)").

To download the filtered results, click image:./media/download-icon.png[Download].

== Take action on results

Select one or more items using the checkboxes in the results table to activate the action toolbar. Available actions are:

* *Delete*: permanently delete the selected files
* *Archive*: move the selected files to a cold storage destination
* *Tag*: apply a business tag to the selected files

For step-by-step instructions, see link:../policies/take-actions.html[Take action with your data].

Available actions depend on your role. See link:../administer/manage-users-roles.html[Manage users and roles].

== Save filters as a policy

Save your current filter set as a policy to reuse it or automate actions on matching files.

.Steps
. Apply the filters that define the data you want to manage.
. Click *Create policy* in the filter toolbar.
. Complete the policy form. See link:../policies/create-policy.html[Create a policy].
