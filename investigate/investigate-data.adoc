= Investigate your data
:icons: font
:imagesdir: ../media/

[.lead]
The Investigation view lets you search and filter file system metadata across your connected ONTAP clusters. You can apply filters to define a targeted data population, take direct action on the results, or save the filter criteria as a reusable policy.

== Navigate to Investigation

In NetApp Console, navigate to *Governance* > *AI Data Engine* > *Investigation*.

You can also open Investigation from any dashboard widget by clicking its *Investigate* link. When you do this, Investigation opens with a filter pre-applied that matches the data shown in the widget.

== Apply filters

The filter panel is on the left side of the Investigation view. You can apply one or more filters simultaneously to narrow the result set.

.Steps
. In the filter panel, click the filter category you want to apply (for example, *File Type* or *Last Accessed Time*).
. Select or enter the filter value.
. Repeat for additional filters as needed.

The results table updates as you apply each filter.

For a complete list of available filters, see link:use-filters.html[Work with filters].

== View investigation results

The results table shows files that match your applied filters:

[cols="1,2",options="header"]
|===
|Column |Description

|File name
|The name of the file.

|Path
|The full path to the file on the ONTAP cluster.

|Size
|The file size.

|File type
|The file extension or type classification.

|Last accessed
|The date the file was last accessed.

|===

== Take action on results

After filtering to a set of files, you can take the following actions from the action bar above the results table:

* *Tag* — apply a business tag to the matching files
* *Archive* — archive the matching files to cold storage
* *Delete* — permanently delete the matching files
* *Save as Policy* — save the current filter criteria as a reusable policy
