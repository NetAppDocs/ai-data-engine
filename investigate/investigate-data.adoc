= Investigate your data in AI Data Engine
:icons: font
:imagesdir: ../media/

[.lead]
When you need to understand what is consuming storage or find files ready for archival or deletion, search and filter metadata across all connected systems. For example, a storage administrator investigating unexpected capacity growth can filter by last-access time and file size to surface terabytes of VM snapshots that have not been touched in years, then act on those files directly.

== Navigate to Investigation

From the AI Data Engine UI, select *Investigation*.

You can also open Investigation from the Overview page by clicking *Investigate* in the _Top consumers by reclaimable storage_ table. Investigation opens with a filter pre-applied for that resource.

Investigation is organized into three sections:

* *Unstructured*: file-based data across NFS and CIFS volumes.
* *Structured*: database tables and schemas.
* *Directories*: directory-level views across connected systems.

Select a section tab to switch between views. The summary count and total size at the top of the page update to reflect the active section (for example, "Unstructured (400M) | 5.7 PiB").

=== Change how results are grouped

Use the *View by* control to change how items are organized in the active view:

* *Unstructured*: group by file, owner, or system.
* *Directories*: group by directory or owner.

NOTE: Structured view has no grouping options available.

=== Refine results with additional filters

Combine any of the filters above with file size, path, system, tag, or policy filters to narrow the results further. For the complete list of available filters, see link:use-filters.html[Work with filters].

.Steps
. Select *Add filter*.
. Select a filter criterion and value.
. Repeat to add additional filters.

Applied filters appear as tags below the filter bar (for example, "Last accessed: 365+ days | File size: >5 GiB"). The results table and item count update each time you add a filter.

To clear all filters, select *Clear filters*.

== View investigation results

The results table shows items that match your applied filters in the active section. When filters are active, the header shows the filtered count and size for that section (for example, "Unstructured (250k / 400M) | 8.3 TiB | Filters applied (2)").

To view additional metadata for an item, select its row. A detail panel opens with additional metadata for the selected item.

To download the filtered results, select image:icon_download_file.png[Download].

== Take action on results

Select one or more items using the checkboxes in the results table to activate the action toolbar. Available actions are:

* *Delete*: permanently delete the selected items
* *Archive*: move the selected items to a cold storage destination
* *Copy*: copy the selected items to another location
* *Tag*: apply a custom tag to the selected items

For step-by-step instructions, see link:../policies/take-actions.html[Take action with your data].

Available actions depend on your role. See link:../administer/manage-users-roles.html[Manage users and roles].

== Save filters as a policy

Save your current filter set as a policy to reuse it or automate actions on matching files.

.Steps
. Apply the filters that define the data you want to manage.
. Select *Create policy* in the filter toolbar.
. Complete the policy form. See link:../policies/create-policy.html[Create a policy].
