= Take action on your data in AI Data Engine
:icons: font
:imagesdir: ../media/

[.lead]
After identifying files using your defined filters, you can take direct action to enforce your organization's data lifecycle policies. For example, a storage administrator who filters to find terabytes of VM snapshots not accessed in over a year can archive them in bulk to a cold storage share, or delete them, depending on retention requirements and business policies.

.About this task
To take action, select one or more items in the Investigation results table using the checkboxes. The action toolbar activates with four options: *Delete*, *Archive*, *Copy*, and *Tag*. To remove duplicate copies of a file, use *Clean up duplicates*. Refer to <<Investigate and clean up duplicate files>>.

== Decide what to do

Choose an action based on how certain you are about the data:

[cols="1,2",options="header"]
|===
|Action |When to use it

|Tag
|You need more time, or need to coordinate with another team, before committing to archive or delete. Tagging tracks the files without changing their location.

|Archive
|The data might still have value, but it doesn't belong in primary storage. Archiving moves it to a lower-cost destination while keeping it recoverable.

|Copy
|The data should exist in a second location, for example for backup or migration purposes. Copying preserves the original in place.

|Delete
|The data is no longer needed and has no retention requirements. Deletion is permanent, so use it only when you are sure.

|===

When data might still have value or require further review, choose tagging, archiving, or copying over deleting. Only delete when you are certain the data is safe to remove permanently.
== Archive files

Archiving moves files to a cold storage destination over NFS or SMB. You can optionally leave a breadcrumb file at the original location.

.Before you begin
* You must have the _AI Data Engine administrator_ role.

.Steps
. In the Investigation view, select the files you want to archive.
. Select *Archive*.
. In the Archive dialog, select the destination volume protocol:
+
* *NFS*: enter the NFS destination folder path.
* *CIFS*: enter the SMB destination folder path in the format `\\Hostname\share_name`. Provide Active Directory credentials: enter the username in `domain\user` or `user@domain` format, and enter the password.
. To create a breadcrumb file at the original location, enable *Leave breadcrumb*.
+
A breadcrumb file helps users understand why a file was moved.
. Select *Archive*.

== Copy files

Copying duplicates files to a destination volume without removing them from the original location.

.Before you begin
* You must have the _AI Data Engine administrator_ role.

.Steps
. In the Investigation view, select the files you want to copy.
. Select *Copy*.
. In the Copy dialog, select the destination volume protocol:
+
* *NFS*: enter the NFS destination folder path.
* *CIFS*: enter the SMB destination folder path in the format `\\Hostname\share_name`. Provide Active Directory credentials: enter the username in `domain\user` or `user@domain` format, and enter the password.
. Select *Copy*.

== Delete files

Deleting permanently removes files from storage and can't be undone.

CAUTION: Deletion is permanent and can't be undone. This action deletes source files even if they contain active data.

.Before you begin
* You must have the _AI Data Engine administrator_ role.

.Steps
. In the Investigation view, select the files you want to delete.
. Select *Delete*.
. In the Delete dialog, type *permanently delete* in the confirmation field.
. Select *Delete*.

.Result
The selected files are permanently deleted from storage.

== Investigate and clean up duplicate files

Use Investigation to find duplicate copies of a file, review their metadata and locations, and identify redundant data that you can remove. You can tag duplicates for review, archive them, or permanently delete duplicate copies while retaining one copy.

.Before you begin
* You must have the _AI Data Engine administrator_ role.

.Steps
. In NetApp Console, go to *AI data hub* > *AI Data Engine*.
. Select *Investigation* > *Unstructured*.
+
The table displays file names, sizes, owners, systems, and tags.
. Optional: Select *Add filter* to narrow the list of files.
. Select a file name to open its details.
+
Review the file's system, storage repository, path, size, timestamps, access, and owner. The *Duplicates* field displays the number of duplicate copies.
. Next to *Duplicates*, select *View details*.
+
The Investigation view applies a *Duplicates* filter that includes files with duplicates and a *File hash* filter that matches the selected file.
. Review the matching files and their locations.
. Select the files you want to clean up.
+
Review the *Selected items* count. To start again, select *Clear selection*.
. Select *Clean up duplicates*.
. Review the estimated number of files matching the current filters that have duplicate copies.
+
NOTE: The count is an estimate. Exact duplicates are recalculated when the action runs, and only files confirmed identical are affected.
. Decide how to handle the duplicates:
+
* Tag the duplicates for review:
.. Under *Action*, select *Tag*.
.. Select *Add*, and then choose the tag to apply. Repeat to add more tags.
.. Select *Submit*.
* Archive the duplicates to a destination volume:
.. Under *Action*, select *Archive*.
.. Under *At the original location*, select *Remove cleanly* or *Leave a breadcrumb*.
.. Select the destination volume protocol. For *NFS*, enter the destination folder path in the format `Hostname:/SHAREPATH`. For *SMB*, enter the destination folder path, and then select *Kerberos* or *NTLM* authentication. For NTLM, enter your Active Directory user name and password.
.. Select *Submit*.
* Delete the duplicates and keep one copy:
+
CAUTION: Deletion is permanent and can't be undone.

.. Under *Action*, select *Delete*.
.. Under *Keep copy with the*, select *Last accessed*, *Last modified*, or *Created*.
.. Under *At the original location*, select *Remove cleanly* or *Leave a breadcrumb*.
.. Select *Submit*.
.. In the *Delete the duplicate copies* dialog, review the number of files to be deleted and the information about retaining one copy.
.. Enter `permanently delete`, and then select *Delete*.

To exit without submitting an action, select *Cancel*.

== Tag files

Tagging applies a business tag to files for classification and tracking.

.Steps
. In the Investigation view, select the files you want to tag.
. Select *Tag*.
. Enter or select the tags to apply (for example, "Archive candidate").
. Confirm to apply the tags.
