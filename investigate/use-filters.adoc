= Work with filters
:icons: font
:imagesdir: ../media/

[.lead]
The Investigation view provides metadata filters that you can use to narrow your results to a specific data population. Apply one or more filters simultaneously to define the files you want to examine or act on.

== Time filters

[cols="1,2",options="header"]
|===
|Filter |Description

|Last created
|Filter files by the date they were created.

|Last modified
|Filter files by the date they were last modified.

|Last accessed
|Filter files by the date they were last accessed. Use this filter to identify cold or stale data.

|===

== File attribute filters

[cols="1,2",options="header"]
|===
|Filter |Description

|File Type
|Filter by file extension or type classification. Select one or more file types from the list.

|File Size
|Filter by file size. Enter a minimum value, a maximum value, or a range.

|File / Directory Path
|Filter by the full or partial path of the file or its containing directory.

|===

== Source filters

[cols="1,2",options="header"]
|===
|Filter |Description

|Data Container
|Filter to a specific ONTAP volume or share.

|System
|Filter to a specific ONTAP cluster.

|System Type
|Filter by the type of storage system.

|===

== Governance filters

[cols="1,2",options="header"]
|===
|Filter |Description

|Tags
|Filter files that have a specific business tag applied.

|Policy
|Filter files matched by a specific saved policy. Policy names appear in the filter list.

|===

== Combining filters
