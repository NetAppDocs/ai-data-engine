:imagesdir: ../media/

Connect Claude Desktop, Cursor, or Visual Studio Code with GitHub Copilot to the AI Data Engine MCP server. After you connect, you can search file metadata and manage tags in the collections that you have access to.

== Supported AI clients

AI Data Engine supports the following AI clients in this release:

* Claude Desktop
* Cursor
* Visual Studio Code with GitHub Copilot

Other MCP clients aren't supported.

AI clients that connect from a cloud provider's service into your network aren't supported. For example, custom connectors that are built into an AI client and called from the provider's cloud can't reach the MCP server in your network. Use the configuration steps on this page instead.

== Before you begin

* An administrator has completed the steps in link:configure-mcp-access.html[Configure Entra ID and MCP access], including these:
** Assigning you the `AIDE Power Users` app role, which you need to tag files.
** Granting your scope access to at least one collection.
** Registering an Entra ID application for your AI client, if your AI client needs one.
* You have the MCP client configuration from your administrator. The administrator copies it from NetApp Console under *AI data hub* > *AI Data Engine* > *Client Setup*. It includes the following:
** The MCP server URL, in the format `https://<mcp-server-host>/mcp/tools`.
** The Microsoft Entra ID tenant ID.
** The client application ID for your AI client.
** The scope for the AI Data Engine application, in the format `api://<application-id-uri>/power_users`.
** The ID of the collection that you want to work with.

== Connect Claude Desktop

Claude Desktop connects to the AI Data Engine MCP server through `mcp-remote`, a small helper that runs on your computer.

.Before you begin

Install Node.js on your computer. The `mcp-remote` helper runs with Node.js.

// RESEARCH Confirm the minimum Node.js version and NetApp's support position for the mcp-remote helper.

.Steps

. In Claude Desktop, open the configuration file `claude_desktop_config.json`.
// RESEARCH Confirm the file path and menu against Anthropic documentation (for example Settings > Developer > Edit Config). Consider linking to vendor documentation instead of repeating the path.
. Add the AI Data Engine MCP server under `mcpServers`. Replace the placeholders with values from your administrator:
+
[source,json]
----
{
  "mcpServers": {
    "netapp-ai-data-engine": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote@<tested version>",
        "https://<mcp-server-host>/mcp/tools?collection_id=<collection-id>",
        "--static-oauth-client-info",
        "{\"client_id\": \"<client-application-id>\"}",
        "--static-oauth-client-metadata",
        "{\"scope\": \"api://<application-id-uri>/power_users\"}",
        "--disable-resource-parameter"
      ]
    }
  }
}
----
+
NOTE: Keep the `--disable-resource-parameter` argument. Without it, Microsoft Entra ID rejects the sign-in request.

. Save the file and restart Claude Desktop.
. When the browser opens, sign in with your Microsoft Entra ID account and accept the consent prompt if it appears.
. In Claude Desktop, confirm that the AI Data Engine server is connected and that its tools are listed.

== What you can do

After you connect, your AI client can do the following:

* List the collections that are available to you.
* Search files by name prefix, file type, or owner. Results include each file's name, path, type, size, last-modified time, and owner.
* List tags and how many files have each tag.
* Add a tag to a file or remove a tag from a file. An AI client works on one file at a time.

Your AI client can't retrieve file contents, add, delete, or modify files, change data sources, or create collections.

=== Search metadata

* "List the data collections that I can search."
* "In the <collection name> collection, find all PDF files."
* "In the <collection name> collection, find files whose names start with `<prefix>`."
* "In the <collection name> collection, list files owned by <owner>."
* "How many <file type> files are in the <collection name> collection?"
* "Show the path, size, and last-modified date of files named `<prefix>` in the <collection name> collection."

TIP: Search filters on file name prefix, file type, and owner. If you ask for files by size, date, or folder, the AI client must page through many results, and the answer might be incomplete.

=== Manage tags

* "List the tags in use and how many files have each tag."
* "Apply the tag <tag name> to the files from my last search."
* "Remove the tag <tag name> from <file name> in the <collection name> collection."
