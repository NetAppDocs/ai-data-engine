= Quick start for governed AI access with AI Data Engine
:icons: font
:imagesdir: ../media/

[.lead]
Set up governed AI access with AI Data Engine by preparing the MCP host and Microsoft Entra ID, configuring a data collection for MCP, and connecting an AI client that can search the collection and tag files through the Model Context Protocol (MCP).

This quick start assumes that you have already link:../data-sources/connect-data-source.html[connected a data source] and that AI Data Engine has scanned and indexed it. The MCP server is deployed together with AI Data Engine. The MCP host name that you use must be on a domain that is verified in your Microsoft Entra ID tenant. You also need permission to register applications and grant consent in Microsoft Entra ID.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png[One] link:prepare-mcp-host.html[Prepare the MCP host]
[role="quick-margin-para"]
On the system where you downloaded the AI Data Engine installer, run the link:prepare-mcp-host.html#run-the-egress-script[egress script] to set up the certificate and the MCP host name. The host name must be on a domain that is verified in your Entra ID tenant. Then confirm that the host is reachable.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png[Two] link:configure-mcp-access.html[Prepare Microsoft Entra ID]
[role="quick-margin-para"]
In the Microsoft Entra admin center, link:configure-mcp-access.html#register-the-ai-data-engine-application[register an application] for AI Data Engine, link:configure-mcp-access.html#define-scopes-and-the-power-user-app-role[define the scope and app role] for power users, assign the role to your users, and link:configure-mcp-access.html#add-redirect-uris-for-ai-clients[add redirect URIs] for your AI clients. Record the tenant ID and the application (client) ID.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png[Three] link:configure-mcp-access.html#set-up-an-identity-provider[Connect Entra ID to AI Data Engine]
[role="quick-margin-para"]
In NetApp Console, add Microsoft Entra ID as an identity provider in AI Data Engine by using the tenant ID and the application (client) ID. Confirm that the provider is connected.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png[Four] link:manage-data-collections.html#create-a-data-collection[Optional: Create a data collection]
[role="quick-margin-para"]
The *All files* collection exists by default and includes every scanned file. In NetApp Console, create more collections to make specific volumes available to AI clients through the MCP server.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-5.png[Five] link:manage-data-collections.html#configure-a-collection-for-mcp[Configure the collection for MCP]
[role="quick-margin-para"]
In NetApp Console, configure a collection for MCP by selecting the identity provider and the power-user scope. Then generate the MCP code snippet for your AI client.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-6.png[Six] link:connect-ai-clients-mcp.html[Connect an AI client and verify the connection]
[role="quick-margin-para"]
In your AI client, add the snippet and sign in with Microsoft Entra ID. Confirm that the AI Data Engine tools are available, and then link:connect-ai-clients-mcp.html#sample-prompts[try sample prompts].
