= Quick start for governed AI access with AI Data Engine
:icons: font
:imagesdir: ../media/

[.lead]
Set up governed AI access with AI Data Engine by preparing Microsoft Entra ID, granting scopes access to a data collection, and connecting an AI client that can search the collection and manage tags through the Model Context Protocol (MCP).

This quick start assumes that you have already link:../data-sources/connect-data-source.html[connected a data source] and that AI Data Engine has scanned and indexed it. You also need permission to register applications and grant consent in Microsoft Entra ID, and your AI clients must be able to reach the AI Data Engine MCP server over the network.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png[One] Prepare Microsoft Entra ID
[role="quick-margin-para"]
In the Microsoft Entra admin center, link:configure-mcp-access.html#register-the-ai-data-engine-application[register an application for AI Data Engine], and then link:configure-mcp-access.html#define-scopes-and-the-power-user-app-role[add the `enterprise_users` and `power_users` scopes]. Create the `AIDEPowerUsers` app role and assign it to the users or groups who tag files in collections, such as storage administrators. Tagging requires both the app role and the `power_users` scope. Record the tenant ID and the application (client) ID. Refer to link:configure-mcp-access.html[Configure Entra ID and MCP access].

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png[Four] Grant scopes access to the collection
[role="quick-margin-para"]
Configure the collection for MCP by link:configure-mcp-access.html#grant-scopes-access-to-collections[selecting the identity provider and the scopes] that can access it. When the configuration is complete and you have selected scopes, MCP is enabled for the collection.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-5.png[Five] Connect an AI client
[role="quick-margin-para"]
Copy the MCP client configuration from *Client Setup* in NetApp Console. It includes the MCP server URL, the Entra ID tenant ID, the client application ID, the scope, and the collection ID. If your AI client needs its own Entra ID application, register it and use its values in the configuration. Then add the configuration to a supported AI client, such as Claude Desktop, Cursor, or Visual Studio Code with GitHub Copilot. To tag files, the configuration must request the `power_users` scope. Refer to link:connect-ai-clients-mcp.html[Connect AI clients].

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-6.png[Six] Sign in and verify the connection
[role="quick-margin-para"]
Sign in with Microsoft Entra ID when the AI client prompts you, and accept the consent prompt if it appears. Confirm that the AI Data Engine tools are listed in your AI client, and then try sample prompts, such as asking for the collections that you can search or listing the tags in a collection. Refer to the sample prompts in link:connect-ai-clients-mcp.html[Connect AI clients].
