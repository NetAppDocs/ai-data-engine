= Manage data collections
:icons: font
:imagesdir: ../media/

[.lead]
Create data collections and enable them for AI access so that connected AI clients can search them. Each collection that you enable defines the scope that AI clients can search through the Model Context Protocol (MCP).

// RESEARCH Help ID help-mcp-collections: confirm the anchor against the staging build, and confirm who owns help ID updates.

== How collections define MCP scope

A data collection is a group of files from volumes that you select in AI Data Engine. When you enable a collection for AI access, AI clients can search the metadata for the files in that collection. AI clients can't search files outside the collections that you enable. To create a collection, refer to <<create-a-data-collection,Create a data collection>>.

You grant access to a collection by assigning it one or more Microsoft Entra ID scopes. Access is granted at the collection level only. Any authenticated user with a matching scope can search every file in the collection.

CAUTION: Before you grant a scope access to a collection, confirm that everyone who has that scope is allowed to search the metadata for every file in the collection.

[#create-a-data-collection]
== Create a data collection

Create a data collection to define the data resources that AI agents can search and retrieve through the MCP server.

.Steps

. In NetApp Console, go to *AI data hub* > *AI Data Engine*.
. Select *Configuration*, then select *MCP collections*.
. Select *Create collection*.
. In *Name*, enter a unique name for the collection.
. Optional: In *Description*, enter a description to help your team understand the collection's purpose. The description can contain up to 512 characters.
. Use the *Systems* and *Protocols* filters to narrow the list of data resources.
. Select the checkbox next to each data resource that you want to include in the collection.
+
The *Selected rows* summary displays the number of selected resources, their scanned capacity, and their scanned file count. To clear the selection and start again, select *Reset*.
. Select *Create MCP collection*.

A confirmation message appears, and the new collection is added to the *Collections* list with a status of *Ready to configure*. Creating the collection doesn't complete its MCP connection configuration.

After you create a collection, configure it for MCP. When the configuration is complete and you have selected scopes, MCP is enabled for the collection. Refer to link:configure-mcp-access.html#grant-scopes-access-to-collections[Select the identity provider and grant scopes access to collections].

== Enable a collection for AI access

.Steps

. In NetApp Console, go to *AI data hub* > *AI Data Engine*.

After you enable a collection, select the identity provider and grant one or more Entra ID scopes access to it so that users can search it. Refer to link:configure-mcp-access.html#grant-scopes-access-to-collections[Select the identity provider and grant scopes access to collections].

== Disable AI access for a collection

Disable AI access for a collection when AI clients no longer need to search it.

.Steps

. In NetApp Console, go to *AI data hub* > *AI Data Engine*.
. Select the collection that you want to disable.
. Turn off AI access for the collection.
. Save your changes.
